# LOST INTERNET — changelog

## 2026-11-25

### `8bffa2d` — Help overlay, focus trap and mobile polish
- `keys.txt` разделён на группы PLAYBACK / INTERFACE / FILES, добавлены описания для всех hotkeys и подсказка про TAB/ESC.
- Кнопка `?` в titlebar открывает справку без поиска в меню.
- Верхнее popup-окно ловит Tab: фокус циклически переходит между его кнопками и не уходит в основной интерфейс; `aria-modal` выставляется только для активного окна.
- Добавлены `safe-area-inset` для titlebar/status/popup и увеличены touch-цели на мобильных с `(pointer: coarse)`.

### `5ce18a9` — Catalog publish rate limit
- `POST /api/catalog` ограничен 10 публикациями с одного IP в сутки.
- Счётчик хранится в D1-таблице `catalog_publish_hits` и обновляется атомарной SQL-записью с `UPSERT`.
- При превышении лимита API возвращает `429` и `{ error: 'publish rate limit exceeded', limit: 10 }`.
- Хеширование IP вынесено в общий хелпер, используемый также для дедупликации лайков.
- Добавлен unit-тест на 11-ю публикацию.

### `81d7427` — Virtualized track table
- Таблица библиотеки рендерит только окно видимых строк плюс 8 строк буфера сверху и снизу.
- Виртуализация включается на 60+ треков; spacer-строки сохраняют высоту скролла, нумерация остаётся исходной.
- Высота окна измеряется через `ResizeObserver`, скролл сбрасывается при смене раздела/поиска/сортировки.
- Логика окна вынесена в `src/lib/table.ts` и покрыта unit-тестами.

### `f359fac` — PWA update notification
- Service worker сообщает приложению о установленной новой сборке.
- Внизу интерфейса появляется красная плашка `NEW BUILD READY // RELOAD TO APPLY` с кнопкой `RELOAD`.
- Пользователь больше не остаётся на старой версии из-за кэша PWA.

### `9772e9f` — FPS readout and accessibility polish
- В строке визуализатора теперь показывается фактический FPS — сразу видно, что режим не ограничен 10 кадрами.
- Кнопки эквалайзера, визуализатора, темы, сортировки каталога, плейлистов и плеера получили `aria-pressed`.
- Навигационные кнопки получили `aria-current`, repeat — явное `aria-label`.
- Popup-окна при открытии переводят фокус на кнопку закрытия и возвращают фокус при полном закрытии.

### `bb50296` — Play metadata, archive races, PWA precache and ID3 art
- `commit()` берёт актуальный трек из ref, поэтому `duration`/`bitrate` от `loadedmetadata` больше не перетираются нулями.
- Удаление и очистка архива инвалидируют отложенное воспроизведение и блокируют запись уже удалённых треков.
- Service worker теперь доустанавливает хэшированные JS/CSS из собранного `index.html`, кэш обновлён до `lost-internet-v9`.
- Тема читается из `localStorage` до гидрации и не перезаписывается дефолтом в memory mode.
- ID3 APIC корректно обрабатывает UTF-16 MIME/description и редкие кодировки.
- Worker экранирует `%`/`_` в поиске и не засчитывает лайк несуществующего трека.

### `d8de658` — Full-rate visualizer in calm mode
- Убрал троттлинг 100 мс, из-за которого визуализатор выглядел как 10 FPS.
- `requestAnimationFrame` теперь работает каждый кадр во всех режимах.
- `CALM MODE` и `prefers-reduced-motion` по-прежнему отключают глитч, idle-синусоиду и быстрое вращение globe.
- Service worker cache: `lost-internet-v8`.

### `bb8864f` — Reactive visualizer and storage/UX regressions
- Визуализатор снова читает `AnalyserNode` в спокойном режиме и показывает `SIGNAL:LOCK`.
- Импорт, удаление и очистка архива работают в памяти даже при недоступном IndexedDB.
- Space больше не перехватывается у кнопок, чекбоксов и ссылок.
- Локальный `/api/*` прокси передаёт IP-заголовки и поддерживает базовый путь `CATALOG_API`.
- Убрал устаревший refetch каталога после лайка.
- Исправлены направление сортировки и ручной порядок плейлиста.
- Кнопка закрытия popup больше не перехватывается drag-ом.
- Тема применяется до загрузки React, без светлой вспышки.
- IDB-транзакции получили обработчик `abort`, чтобы не блокировать UI.
- Service worker обновляет кэш через `waitUntil` и не кэширует неуспешные навигации.

### `9aa128f` — Player UX and local catalog proxy
- Откат/коммит crossfade при ошибке воспроизведения.
- Горячие клавиши после кнопок, ручной порядок плейлиста, сортировка archive/recent.
- Сообщения об ошибках IndexedDB, защита от повторного импорта.
- Локальный прокси `/api/*` на рабочий Worker, тема применяется к host-chrome.
- Ограничение высоты popup, aria-метки, защита от повторного лайка.
